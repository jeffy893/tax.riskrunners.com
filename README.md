# Tax Playbook

**US Tax Code Strategies — Through Storytelling**

Twelve screenplays that teach real, legal tax reduction strategies from the Internal Revenue Code through dramatic storytelling. No textbooks. No jargon walls. Just characters navigating audits, planning "heists," and arguing in Tax Court — while teaching you how the code actually works in your favor.

## Quick Start

Open `index.html` in any browser. It's the home page with links to all twelve screenplays.

Each screenplay is a standalone HTML file — no server, no dependencies, no build step. Just open and read.

## Regenerating

The screenplays are generated by `generate_screenplays.py`. To regenerate:

```bash
pip install Pillow
python3 generate_screenplays.py
```

This generates unique header images for each screenplay using Pillow and outputs 12 standalone HTML files plus the index page.

Requirements:
- Python 3.10+
- Pillow (`pip install Pillow`)

## Design

- Light, warm color theme (cream background `#faf8f5`, dark text)
- Each screenplay has a unique accent color and header image
- Responsive layout, print-friendly CSS
- Header images generated with Pillow and saved to `img/` directory
- Screenplay text formatted with character names centered and bold, stage directions italicized, and scene headings accented
- Navigation: sticky top bar, bottom prev/next cards, floating scroll-to-top
- Footer with links to Risk Runners ecosystem

## Genres

The screenplays use three dramatic sub-genres to make tax code engaging:

- **The Audit (Interrogation Room):** IRS agents vs. taxpayers — teaching deductions and elections through intense, documented confrontations
- **The Loophole (Heist/Caper):** CPAs and advisors explaining complex structures like they're planning Ocean's Eleven — breaking the fourth wall with math
- **Tax Court True Crime:** Based on real provisions and court-tested strategies, dramatized through courtroom and advisory scenes

## Disclaimer

These screenplays are educational entertainment. They describe real IRC sections and strategies but do not constitute tax advice. Consult a qualified tax professional before implementing any strategy.
